## 📖 项目简介

**「VitalPulse 若水」** 是一款专为久坐办公人群、极客工程师与硬核健身爱好者设计的 Windows 桌面端健康管理伴侣。

它打破了市面工具“单纯打卡”或“独立计时”的单点孤岛，以**科学水合节律**与**多维微健康习惯**为基础，深度融合**「心流番茄钟」**与**「无损实时合成自然白噪音」**，构建起**「专注工作 ➔ 舒缓小憩 ➔ 及时水合 ➔ 习惯养成」**的身心正向闭环。

面向使用者视角的完整介绍见 [产品介绍.md](产品介绍.md)。

## ✨ 核心特色与功能矩阵

### 1. ⏱️ 心流专注 · 水合律动番茄钟 (`FocusView.vue`)
市面上的传统番茄钟仅关注时间消逝，却容易导致使用者在高度专注中忽略饮水与腰椎健康。若水番茄钟专为身心协同打造：
- **4 大心流预设矩阵**：
  - **经典番茄 (25m + 5m)**：平衡日常工作节奏，高效推进任务与文档；
  - **深度心流 (50m + 10m)**：专为高强度编码、长文撰写与系统设计定制；
  - **闪电突击 (15m + 3m)**：专克拖延，攻坚单点棘手 Bug 或列清晨间 Todo；
  - **自由定制 (10~90m)**：自主平滑微调专属心流时长与步进。
- **身心水合律动闭环**：
  - 专注倒计时达成后，自动触发柔和庆贺音效与五彩纸屑，并自适应弹出**工间补水达成卡片**；
  - 提供 `+150ml` / `+200ml` / `+300ml` 一键补水快捷打卡，引导站立舒展腰椎，让大脑满血重启。
- **借鉴标杆的静谧水感视觉 (Tide / Calm 美学)**：
  - 采用深邃舒缓的 **海洋心流渐变主键** (`from-sky-500 via-sky-600 to-blue-600`)；
  - SVG 矢量级 **潮汐渐变流光进度环** (`#0284C7` ➔ `#0EA5E9` ➔ `#14B8A6`)，赋予微呼吸律动；
  - 透光水感微胶囊任务标签（健康办公、代码沉浸、深度研读等），彻底杜绝沉重纯黑实心框；
  - 统一清爽天蓝双联动开关，消除蓝绿杂糅违和感。

### 2. 🎧 无损物理实时合成自然声景 (`src/utils/audio.ts`)
完全基于现代浏览器 **Web Audio API** 纯数学节点图谱（双二阶滤波器、粉红/布朗噪声缓冲器、次低频双耳振荡器）实时程序化合成，**零外部 MP3/WAV 音频文件依赖**，零网络延迟与零资源消耗：
- 💧 **高山清溪**：潺潺泉鸣与流动水珠，平复心率与工作紧张，营造清凉专注的心流场域。
- 🌧️ **雨落窗台**：双层淅沥雨声掩蔽突发外界噪音，适合深度心流编程与设计。
- 🌲 **林海松风**：微风轻拂松针与树叶沙沙声，有效舒缓久坐屏幕后的眼部疲劳。
- 🔥 **围炉暖火**：融融柴火与随机爆裂脆响，营造踏实温暖的庇护感。
- 🌊 **潮汐海浪**：8 秒规律浪涌与缓慢退潮，与 4-7-8 深度呼吸节律同频共振。
- 🌌 **深空星云**：低频阿尔法双耳共振与太空白噪音，深夜灵感迸发与深度入定。
- **智能协同体验**：
  - 支持弹窗**实时试听**与**一键应用**；
  - 支持精细音量推子无级调节与平滑淡入淡出（Cross-fade）；
  - 支持随专注模式自动启停：番茄钟开始时自动播放，暂停或结束时轻柔淡出。

### 4. ⚡ 硬核健身与围训练期模式 (`AppMode`)
顶栏一键无缝切换 **日常办公模式 ⇄ 硬核健身模式**：
- **定制化补水算法**：
  - 综合考量基础体重、当日训练强度（休息日 / 轻度+300ml / 力量+600ml / 高强+1000ml）；
  - 自动叠加**肌酸服用期**额外水合加成（+500ml）与**高蛋白增肌期**代谢加成（+300ml）。
- **围训练期黄金节律补水 (Peri-Workout)**：
  - 07:00 晨起代谢激活 (450ml)
  - 12:00 训前储水充能 (700ml)
  - 16:00 训中电解质水 (600ml)
  - 18:30 训后蛋白吸收 (700ml)
  - 21:30 夜间肌肉修护 (450ml)
- **健身专属饮品与微习惯**：
  - 内置乳清蛋白冲饮 (0.90)、支链氨基酸 BCAA (0.98)、训前氮泵 (0.88)；
  - 专属习惯打卡：每日一水肌酸、乳清蛋白补充、训后肌肉拉伸、深蹲体态复位。

## 📦 关于安装包与体积说明

### 为什么解压后体积约为 180MB？
若水桌面应用未打包压缩前的解包目录（`release/win-unpacked`）体积约为 180MB，这是 **Electron 架构** 的典型特征：
1. **自带完整的 Chrome 浏览器引擎**：
   - 包含 Chromium Blink 布局内核、V8 JS 引擎、Web Audio 音频管线、Direct3D/Skia 硬件图形加速器；
   - 确保应用在 Windows 10/11 的任何机器上脱离外部环境依赖、100% 稳定高帧率渲染。
2. **自带 Node.js 运行时**：提供托盘通信、文件系统特权读写。
3. **真实业务代码极其轻量**：
   - 若水全部的 Vue 业务组件、CSS 样式、状态流转与 6 款白噪音算法加起来**仅约 360 KB**（占总安装包体积不足 0.2%），其余 99.8% 均为基础系统底座。
4. **发行版安装包压缩率**：
   - 制作成 Windows 安装包（`.exe` 安装程序）或 `.zip` 压缩包后，因底座高重复度，**实际下载体积仅在 60MB 左右**。
